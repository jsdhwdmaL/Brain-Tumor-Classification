# Brain Tumor Classification  
Classify types of brain tumors using CNN and different optimizers.
### Three Optimizers are used: 
1. Adaptive Moment Estimation (Adam) -- 93% accuracy
2. Stochastic Gradient Descent (SGD) -- 90% accuracy
3. Genetic Algorithm (GA) -- 95% accuracy
### Results
- Most precise diagnosis on pituitary tumor and the least on meningioma tumor

### Dataset
- https://www.kaggle.com/datasets/sartajbhuvaji/brain-tumor-classification-mri
